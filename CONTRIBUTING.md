# Contributing

Contributions are welcome. Read [AGENTS.md](AGENTS.md) and [the sprint plan](docs/sprint.md).

- Keep changes focused and independently testable.
- Use a feature branch and pull request.
- Include tests or a reproducible manual validation procedure.
- Mark synthetic or illustrative geographic data; cite authoritative sources for real-world claims.
- Do not commit proprietary map imagery, credentials, personal data, or giant render caches.
- Document new QGIS/Blender version requirements and external assets.
